# Revisor de planos — WorldTeams

Detector de textos superpuestos en planos PDF, con acceso por Google (allowlist) y video obligatorio.

> README en construcción: se completa al final con cómo correrlo, variables de entorno,
> decisiones técnicas, limitaciones y medición del detector.

## Correr en local

```bash
npm install
cp .env.example .env.local   # completar valores
npm run dev
```
